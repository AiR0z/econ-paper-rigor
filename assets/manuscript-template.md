# Abstract

State the question, setting, design, principal evidence, and supported claim.

# Introduction

Define the question, contribution, and scope.

# Data and measurement

Describe provenance, sample construction, variables, and limitations.

# Empirical design

Define the estimand, estimator, inference, and identifying assumptions.

# Results

Report estimates with uncertainty and calibrated interpretation.

# Robustness and limitations

Address specific threats and remaining uncertainty.

# Conclusion

Summarize what the evidence supports without extending the claim ceiling.
